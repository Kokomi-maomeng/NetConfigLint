# v3.1 Debian / Windows 使用体验修复

本版本按 2026-10-05 的 L01–L14 处理。原始报告与证据保留在本地忽略目录，发布源码只包含实现、合成回归和本记录。命令识别、资料收录与实际设备语义验证仍遵守 [命令支持范围](v3.0-command-support.md)。

| 编号 | 修改 | 验收重点 |
| --- | --- | --- |
| L01 | 查询候选不携带全部语法和逐语法来源；冷加载、宽前缀及大文本交互交给后台，取消和过期结果不改当前窗口 | 双编辑区空查询、空行 Tab、输入/取消、冷暖路径 |
| L02 | 详情单独取数，语法和来源按页显示，可检索完整组 | auto undo 大组、滚动、翻页、搜索与关闭 |
| L03 | 清理仅允许精确产品目录及认可子目录；拒绝候选及祖先链接/重解析点，遍历不跟随嵌套链接 | 无关同名祖先、近似目录、符号链接与 junction 合成对照 |
| L04 | 持久隐私策略、历史文件与跨进程锁统一；提交分析时捕获授权版本，写入时复查；切回窗口或历史刷新缓存 | 独立进程 full→summary/off，过期分析与重新启用后的旧任务 |
| L05 | 打开时记录文件身份和内容摘要；保存前及替换前复查，提供取消、另存、放弃编辑重载、明确覆盖 | 外部编辑/替换/删除，确认后再变化，失败保留 dirty |
| L06 | 全文保留紧凑编辑记录，换页/搜索/跳转不清除全局 undo/redo | 双编辑区跨页输入、删除、补全、清空与重做 |
| L07 | 全文选择、复制、剪切、粘贴替换与清空有明确范围，当前页动作另标注 | 首页/中页/末页，全文一致、撤销与分析/保存范围 |
| L08 | 查询参数位置呈现参数能力、语法、说明和来源 | sysname、VPN 及自由参数，两编辑区原文不变 |
| L09 | Ctrl+S 按编辑区/其搜索框焦点保存；模态查询不保存其他编辑区 | 正文/草稿/搜索/模态焦点，成功/失败/取消反馈 |
| L10 | 链接保存先显示解析目标，明确选择更新目标才写入；保留链接身份，目标变化重新确认；断链拒绝覆盖 | 相对/绝对链接、目标替换、断链、错误权限 |
| L11 | 尊重 POSIX 只读位和 Windows 只读属性；Windows 检查实际写访问，拒绝 DACL 禁止和共享锁 | 原文件保持、另存可用、dirty 不丢失 |
| L12 | 新文件默认私有；POSIX 覆盖保留 mode/owner/group/可用 xattr，Windows 保留 owner/group 并由 ReplaceFileW 合并 DACL/streams | 0600/0640/0644、特殊 Windows DACL/owner/ADS，元数据失败不静默降级 |
| L13 | 草稿使用唯一私有临时文件、fsync 与原子替换；POSIX 目录 0700/文件 0600，Windows 当前账户/System/Administrators 保护 DACL | 不同 umask、已有共享权限、失败与链接拒绝 |
| L14 | 查询、参数和详情按钮使用应用中英文文案 | 编译包语言切换、关闭按钮和 Esc |

文件保存的 Windows 元数据策略依据 [Microsoft ReplaceFileW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-replacefilew)。替换保留同目录恢复备份；部分文件系统失败时优先恢复原文件，无法安全恢复则保留恢复文件并显示位置，不把唯一副本当临时文件删除。保存使用多次身份核验，但不是所有文件系统的原子比较交换或协作锁协议；网络盘、云同步客户端与特殊安全标签不作普遍保证。

## 验证与发布状态

Windows 完整回归为 1056 项通过、8 项平台条件跳过；随后新增的异常保存、真实 QML 确认窗口与生产冒烟用例另作定向复核。Debian 完整集合未再发生此前的累计运行 SIGSEGV；QA 源码副本最初缺少 Git 元数据导致的 14 个安装资料测试 setup error，补齐后对应文件全部通过。合并完整集合及该次定向复核，独立用例为 1052 项通过、13 项平台条件跳过，源码覆盖率 90.44%；这不是一次无中断全量运行的结果，最终仍以同一发布提交的 CI 全量门槛为准。

格式、Ruff、Mypy、Bandit 和固定依赖审计已通过。保存边界另覆盖 Debian 上真实 xattr、不同 UID/GID 保留，以及 Windows 上真实 DACL/owner、只读属性、共享锁和 ADS；部分 Win32 替换失败及磁盘错误采用合成故障注入，不等于在故障磁盘上验收。恢复文件路径在窄窗可完整滚动阅读，补全线程异常保留原文并提供应用内失败反馈。

Debian 原生 GUI 的 50% CPU 限额复核还发现，高亮会在纯文本未变化时再次发出 textChanged，错误取消首次后台 Tab 请求。本次改为按正文和光标的实际变化撤销请求，双编辑区新增真实 rehighlight 回归；相同冷启动操作约 1.64 秒返回 8 个候选且保留焦点。这个时间只说明该次虚拟机观察，不作为所有机器的响应时间保证。

正式资产须由完整 CI 的 Windows/Linux 编译任务产生，并通过源码历史、原生安装包载荷、便携 ZIP 和版本身份独立门槛。发布前复核 Windows 编译包、Debian 13 GUI 安装运行；发布后从公开入口下载并对比大小及 SHA-256。CI、原生实测和公开下载的最终记录随 Release 发布；本节的本地回归计数不替代这些门槛。macOS 本次仅做代码兼容性及托管质量检查，不生成新 PKG，也不覆盖本地旧的合格 macOS 包。

全部功能测试保留在 14 个平台/Python/Qt 组合；15,000 行配置的 2 秒性能门槛不变，由 Ubuntu / Python 3.13.15 / Qt 6.11.2 发布组合在覆盖率统计之外单独执行。其它组合不重复执行这一依赖宿主调度的计时门槛，macOS 托管检查不构成实体机器性能保证。

W-OBS01 是原报告中的 Windows COM 异常观察，原先进程仍通过功能断言并正常退出。本次保留 faulthandler 的原生单项复核暂未复现；没有据此认定原根因解决。实体 Mac 环境不可用，用户要求以代码兼容性检查为范围；托管检查不代表实体硬件验收。没有签名身份时发布包必须标明 unsigned，不能称为已签名。
