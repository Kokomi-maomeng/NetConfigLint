# v1.5 华为专项修复与验证

本专项基于已整合的 `34f606f585141404475226eb75cc40534bccdf5f`，复核 Huawei
detector、parser、profile、snapshot 和全部 50 条注册规则。修复重点是受支持 VRP
配置形式的视图归属、有效状态、地址族 / VPN 隔离，以及规则之间的引用一致性。
新增合成回归，不将无法确定的型号行为、扩展命令或不完整运行数据升级为确定结论。

本次交付为源码、专项测试和此报告。版本、默认模式、模式说明、GUI、CI、发行构建和发布流程
均由主任务继续处理；本专项没有推送、打标签或发布。

## 仍保留的边界

- 配置导出、缩进片段和明确初始视图采用有界语法；不是任意交互式命令记录的执行器。
  未覆盖最短命令缩写、全部引号 / 名称语法、设备交互约束及所有撤销副作用。
  未知命令继续出现在未解析覆盖中，受支持的明确替换 / 撤销不等于实现完整 CLI 状态机。
- 多 BGP instance、未知 AF、动态 peer group、复杂 AS 继承及未支持扩展仍不完整。
  本轮隔离已支持的公网和 VPN AF，未实现全部 AF 运行快照或 OSPFv3 全部协议语义。
- 未编号 ACL 只证明有规则，未猜测自动 rule ID；同 ID 局部编辑不模拟全部设备合并行为。
  未支持的协议、端口、附加匹配及 profile 能力不能用于确定的全放行结论。
- 未支持的静态 next-table / 无 IP 下一跳扩展，以及 track、BFD、NQA 等运行依赖，
  不作为确定有效的 BGP 路由证据；配置候选始终不等于本地 RIB 或实际转发成立。
- 快照只支持明确识别的输出布局，完整性、设备身份、VPN / AF、失败和冲突证据继续限制结论。
  没有采集到状态不代表 up，也未验证采集时效、真实设备或 FIB 转发。
