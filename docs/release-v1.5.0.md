# NetConfigLint v1.5.0

本次更新以 v1.4 审计问题修复为主，完整对应 F01–F26，并继续完善华为配置检查。
逐项改动和反例见 [审计修复汇总](v1.5-audit-repairs.md)。

## 使用变化

- 默认采用“配置片段”模式。只粘贴部分配置时，未提供的内容不会直接判为缺失错误。
- 三种检查模式的说明重新整理；完整配置与配置加运行快照仍可手动选择。
- 大量诊断的筛选保持流畅，点击结果仍定位到原始配置行，导出保留全部级别。
- 显示解析覆盖范围；没有发现诊断不再暗示所有输入都已被完整检查。
- 损坏的历史文件不会阻止启动；历史开关状态和页面布局同步更新。
- Markdown / TXT 补齐对象、来源范围和置信度；修复受限终端编码下的 CLI 输出。
- 分析支持取消并限制输入、诊断及展开工作量，超限会明确说明结果不完整。

## 华为检查修复

路由与运行快照依据设备、VPN、地址族和采集完整性使用证据；ACL 的编号、名称、别名和地址族
采用一致身份；修复 BGP network、peer group、OSPF、VLAN all / undo、配置片段视图和安全检查
中的误判。设备型号与版本必须有明确证据，描述文字不能触发某型号的默认值。
华为专项还修复了接口分隔名称、嵌套 / 重入视图、有效撤销、分域 peer / group、同名异族
prefix-list、VPN 绑定的关联清理与快照冲突；详见 [17 项专项修复](v1.5-huawei-repairs.md)。

未支持的命令或不足以验证的结果继续保留 Unknown / Cannot Verify。

## Windows 便携版

下载 `NetConfigLint-1.5.0-windows-x64-portable.zip`，完整解压后运行其中的 `NetConfigLint.exe`。
无需安装 Python，不要只复制 EXE 或直接在压缩包内运行。默认不记录历史；启用后，精简历史保存在
软件旁的 `history` 目录。

分发包含完整许可材料、第三方声明和记录实际文件哈希的 `SBOM.json`。本次发布继续提供 x64
Windows 便携包；源码支持的 Python / Qt 版本和三平台实际验收范围见
[验收报告](v1.5-acceptance.md)。

配置分析在本地完成。显式导出的配置和诊断可能包含网络资料，请按实际用途保管。
