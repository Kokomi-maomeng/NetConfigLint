# v2.5 repairs and qualification

This release replaces the H3C-to-Huawei adapter with independently maintained Comware parsing,
effective-command reduction and rule implementations. Neutral models/dispatch and protocol-neutral
message hypotheses remain shared. An AST guard rejects cross-vendor imports.

## Repairs

| Audit item | Change and acceptance condition |
| --- | --- |
| F01 | FULL mode consumes available Huawei operational evidence with completeness/VRF/family guards; a complete same-scope empty RIB can verify absence. Partial captures cannot. |
| F02 | History restoration clears bundle/export/input metadata and restores the selected source. |
| F03, F18, F19 | Incomplete CLI analysis exits 2, read limits produce controlled errors, and all five supported CLI modes are accepted. |
| F04 | H3C owns final diagnostics; no adapter reconstruction or duplicate budget charge. 1,100 missing-VLAN issues finish once each. |
| F05, F06 | Failed/unsupported operational input stays UNKNOWN and semantic coverage stays partial. Invalid SNMP/NTP/clock shapes are not semantic recognition. |
| F07, F17 | ACL port/prefix/mask ranges are checked; long VLAN-interface IDs and numeric conversions are bounded. Invalid input cannot crash the public analysis API. |
| F08 | OSPF 2-Way needs network type and local/peer role evidence; the neighbor table alone produces UNKNOWN. |
| F09, F10 | VTY class/range inheritance and OSPF process/area/interface evidence are scoped; remaining line capacity and omitted defaults are not assumed. |
| F11, F12 | History writes respect the reader's aggregate UTF-8 quota, merge current disk state under QLockFile, and replace a unique temporary file atomically. |
| F13, F14 | Metadata scrolls within a bounded area; narrow windows use stacked, scrollable cards and fit logical screen dimensions. |
| F15 | Decode/preview and history persistence run in workers. Large documents use explicit read-only preview pages with complete source retained for analysis, history, saving and export; jumps switch pages, and search covers the current page. Line numbers are bounded by visible rows. |
| F16 | H3C section extraction is one pass with cooperative checkpoints. Repeated headers do not cause quadratic copying. |
| F20 | Scratch reads accommodate the UTF-8 byte size of the existing character quota. |
| R01 | Release runtime moves to qualified Python 3.13.15; Qt remains 6.11.2. |
| R02 | Reused workflow head SHA and ZIP SBOM version/source commit must match the dereferenced release tag. |
| R03 | Windows signs before generating/verifying the final payload inventory. macOS keeps the final signed inventory outside the sealed app. |
| R04 | MSI checks actual Windows build 17763; the GUI launcher reports unsupported older builds. |
| R05 | macOS standalone and staged installer payloads pass license/inventory gates. Mach-O relocation matching checks architecture, executable sections and supported loader changes. |
| R07 | New commit identity uses GitHub noreply. Existing historical public metadata/caches are outside the new payload and are not claimed erased by a release. |
| I01–I03 | Unreferenced copied rules/helpers are removed; UTF-16 BOM decoding, client Wayland plugins, macOS shortcuts and reduced animation preference are added. |

**R06 is retained by explicit user request:** full plaintext local history remains enabled by default.
History/scratch data remains sensitive and is never included in the release payload.

## Validation record

Local Windows source checks on Python 3.13.15 / Qt 6.11.2 include a 735-test full run,
supplementary Comware/GUI regressions and 90.32% combined coverage. The separate performance
test passes outside coverage instrumentation. A native Windows Direct3D 11 desktop probe
passes vendor/mode selection, responsive layouts, history, search and three exports. Loading
a synthetic 40,000-line file retains the complete source, uses bounded preview pages and
records a 0.11-second load with a 0.08-second maximum GUI timer gap on that host.
A Debian 13 GNOME desktop source run passes 739 tests. Unlocked GNOME Wayland and XWayland
windows pass the same native interaction probe; Wayland also passes with software rendering.
The large-file desktop load is below 0.10 seconds in those synthetic probes. The follow-up
desktop review also fixes wrapping of English severity filters in narrow panels and an
undefined preview font. A fresh Windows ZIP extraction has passed native/software smoke,
three exports and restricted standard-user acceptance with a system-only PATH.
CI build, license, security and public-download gates apply to the final release; their
immutable workflow links and downloaded-asset hash are recorded in the GitHub release notes.

Only a Windows portable ZIP is published for v2.5. No assertion is made that finite tests prove
every device command, hardware combination, OS patch, DPI or GPU works. macOS physical desktop
testing is unavailable; its static review and any CI evidence are stated separately.
