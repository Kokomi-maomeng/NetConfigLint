## 本阶段验证结果

- 原基线：192 个 pytest 测试通过；修复后：277 个测试通过，27.14 秒。
- Ruff 格式、lint、严格 mypy 通过（68 个应用 Python 文件）。
- Windows 原生 QML 启动、浅色中文/深色英文及三个导出通过，`qml_errors=[]`。
- 原审计 4,093 条诊断压力脚本重跑：分析 0.070 秒；切到空级别事件延迟 0.067 秒；残留卡片 0。
  原审计相同场景为约 21.86 秒。这是本次环境测量，不是所有硬件的时延承诺。
- 已检查原生工作区截图；关键控件、诊断与配置区正常显示。

旧规则测试现在显式选择 Huawei，避免把规则语义断言绑定到不可靠的 `sysname` 自动识别。
旧快照缺失测试补充明确结束提示符；GUI 筛选测试重新查找当前卡片，不依赖模型重置前的实例。
这些修改保留了原业务断言，并新增了对应反例。
