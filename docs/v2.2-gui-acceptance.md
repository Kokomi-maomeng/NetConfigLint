# NetConfigLint v2.2 本地 GUI 验收

此记录对应 v2.2 源码与 Windows 便携 ZIP 的验收证据；公开发布状态以 GitHub Release 为准。

## 本轮界面与行为

- 保留原有操作，删除多余菜单和独立操作行。顶栏依次放侧边栏开关、打开、导出、模式、厂商、显示和关于；操作热区约 40–44 逻辑像素。侧边栏收起后宽度为零，窄窗口展开时覆盖工作区。
- 删除侧边栏分隔线、卡片悬停描边和分栏悬停细线。诊断级别按钮在最窄布局中仍保持一行、等高等宽；卡片拖动提示改为“移动卡片位置”。分析与保存按钮固定在各自标题右侧并使用主题色；卡片、按钮和背景也增加克制的主题色调。
- 窗口保留普通尺寸及位置，最小化和最大化增加内容过渡。最大化后最小化，再按任务栏式恢复，会回到最大化状态。显示菜单切换面板不改变窗口状态。
- 设置分组恢复展开 / 收起动画；历史开关由控制器状态驱动，确认关闭后可再次打开。清空历史须确认，确认后关闭设置并回到配置检查。提示卡片出现和消失均有动画。
- 关于页标题去掉句号，两段许可与静态分析提示移到“项目与作者”之前；再次点击关于返回原来的配置或历史结果。编辑区回车后的当前行计数与光标一致。
- 历史列表用本机时区显示 `年-月-日 时:分:秒`；诊断结果在厂商下方显示同一记录的时间。临时编辑区仅在点击保存时写入 `temporary/editor.txt`；Windows 便携包的历史文件位于同级 `history/history.json`，重启后仍能读到保存文本。
- Debian 13 上发现内置可变字体被 Qt/fontconfig 仅识别为 `Thin`。已将 Noto Sans SC 与 Roboto 改为明确的 Regular、SemiBold 静态字体；两端均验证实际字重匹配，Linux 图形截图中的正文和标题恢复正常粗细。静态字体由先前仓库内的 OFL 可变字体使用 fontTools 4.66.0，以 `wght=400/600`（Roboto 另设 `wdth=100`）实例化，原有许可文件保留。窗口可见性信号改为显式处理，清除了 Linux Qt 的弃用警告。
- 配置内容与临时编辑区选中空行时，空行本身会显示选区背景；两处编辑器各自支持 `Ctrl++`、`Ctrl+=` 与 `Ctrl+-` 缩放。关于页两段许可与分析提示只去掉末尾句号，保留段内断句。
- 启动、关闭以及最大化 / 还原时，对窗口内容增加淡入淡出和轻微缩放过渡；关闭请求立即保存窗口状态，再完成退场动画，以免设置丢失。

## 验证

- 源码 Qt 离屏交互覆盖设置动画、提示消失动画、开关关闭和再启用、清空确认、编辑区鼠标输入和保存、窄卡片布局、关于返回、历史时间一致性、异步分析结果持续显示以及窗口最小化恢复。Windows 真实程序点击“打开”并用系统文件选择器载入 `sysname PACKAGED_OPEN_OK`，随后点击“分析”；诊断卡片显示厂商、时间及结果，时间与新建历史记录一致。点击该历史记录后结果可恢复。
- Windows 原生窗口在 125% 缩放屏幕中处于可用区域；最大化 → 最小化 → `SW_RESTORE` 后仍最大化。真实便携程序点击临时区“保存”后，在程序文件夹创建 `temporary/editor.txt`；写入合成样本并重新启动，文字重新显示。
- 便携 ZIP 自动验收包含原生与软件渲染、三个导出格式、零 QML 错误、Unicode / 空格解压路径、受限普通用户、仅系统 PATH、无控制台子进程、正常退出和默认不生成历史。
- Windows 完整 pytest：`574 passed`；Debian 13 完整 pytest：`574 passed`。新增交互测试覆盖两处编辑器空行选区与快捷键缩放，以及窗口启动、最大化、还原和关闭动画。严格 mypy 覆盖 86 个源码文件；Ruff、格式及 `git diff --check` 通过。Windows 解压验收通过原生与软件渲染、三种导出、零 QML 错误、普通用户、Unicode / 空格路径、默认无历史、无控制台子进程和正常退出。真实 Windows 窗口中再次验证了空行选区、键盘缩放、打开文件、关于页文字及最大化 / 还原 / 关闭。

## 产物与平台边界

- `release/NetConfigLint-2.2.0-windows-x64-portable.zip` 与同名 `.sha256` 为本地验收产物，程序未签名。ZIP 长度 **62,568,057 字节**，SHA-256 为 `d43aa778eda66cb162372f54b76eb304c4d8392b69f97523455b6c738e7cce3a`。GitHub Actions 发布构建会独立生成 ZIP，须单独核对其实际校验值。
- Debian 13 虚拟机已通过 SSH 连接，在隔离 Python 环境以 Qt 6.11.2 的 X11/xcb 软件渲染后端完成真实 GUI 冒烟：界面加载、Huawei 合成样本分析、三种导出、明暗主题截图及零 QML 错误；完整自动化交互测试使用 Qt 软件离屏后端。macOS 没有可用测试环境，仅检查跨平台源码与构建脚本；不能据此宣称 macOS 原生运行已验收或三端零缺陷。
