# v2.4 command inventory and diagnostic language acceptance

This release adds a source-linked **command-family inventory** for Huawei VRP and H3C Comware 7.
It separates three kinds of evidence:

1. **Normalized by parser:** a command is represented in the analyzer's normalized model or an
   explicit parser branch. This does not assert that the device will accept it or that every
   model-specific argument and interaction has been validated.
2. **Documented family, semantics unchecked:** the command is in a documented family, but the
   exact form, view, target hardware and effective behavior have not been checked. These lines
   no longer create one `H3C-CMD-001` alert per familiar command. They remain source mapped and
   make `semantic_complete` false.
3. **Unparsed / unsupported:** no safe family match was made. H3C keeps individual `H3C-CMD-001`
   evidence and its summary. Existing Huawei unsupported syntax and context warnings remain.

The catalog has explicit patterns for spanning tree, information center, LLDP, interfaces, VLAN,
IRF, IP, routing, ACL, QoS, management services, multicast and VXLAN/EVPN. A family match does
not activate device-specific feature facts or suppress a parser's structural diagnostic. Chinese
prose annotation lines are excluded from command counts; `description` with Chinese arguments
remains a command. The coverage panel shows both normalized and family-only counts and names the
family, so the user can see what was classified without mistaking the result for full validation.

## Source and version boundary

- [H3C Comware 7 spanning tree commands](https://www.h3c.com/en/d_202511/2698540_294551_0.htm)
  document `stp global enable`, mode, region and port behavior.
- [H3C information center commands](https://www.h3c.com/en/d_201904/1174365_294551_0.htm)
  document log hosts, source selection, log buffer and output controls.
- [H3C S6805/S9850 Release 6715 command-reference index](https://www.h3c.com/en/Support/Resource_Center/EN/Home/Public/00-Public/Technical_Documents/Reference_Guides/Command_References/H3C_S6805_S9850_CRs_Release_6715-18388/00/)
  maps the wider feature families.
- [Huawei STP/RSTP/MSTP configuration](https://support.huawei.com/enterprise/en/doc/EDOC1100466171/c9a6630d/stp-rstp-mstp-configuration)
  and [Huawei information management commands](https://info.support.huawei.com/enterprise/en/doc/EDOC1100439389/39d8e202/information-management-configuration-commands)
  ground the two reported basic families.
- [Huawei CloudEngine S8700 V600R024C10 command-reference index](https://support.huawei.com/enterprise/en/doc/EDOC1100459368/8601ba7b/basic-configuration)
  identifies the wider categories; it is **not** proof that each syntax works on every VRP target.

These sources span specific products and releases. No finite generic catalog can claim every
Huawei/H3C command, hidden default, board dependency or live state. The program preserves
unknown input and expresses this uncertainty in coverage instead of asserting universal support.

## Diagnostic language

The GUI applies Chinese templates to diagnostic messages, explanations and suggestions when
Simplified Chinese is selected, and keeps the English source when English is selected. CLI
keywords, protocol names, object identifiers and command examples remain verbatim. The static
translation audit walks literal diagnostic prose in source code, including f-string shapes;
runtime tests also cover synthetic vendor fixtures. New H3C operations/security, platform and
view-analysis prose is translated. Unsupported future prose remains detectable by the audit.
