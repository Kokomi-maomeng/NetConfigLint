# v1.4 acceptance evidence

## Automated coverage

The suite contains 192 tests, including the existing parser, rules, CLI, profile, snapshot,
privacy/history and performance checks. New checks exercise actual QML windows and events:

| Requirement | Verification |
| --- | --- |
| Empty input and result status | Disabled Analyze button; no worker or error for whitespace; status within Diagnostics |
| Current results | Source/mode/vendor invalidation; stale completion and exception rejection |
| Bilingual UI | Catalog key parity; diagnostic translations for every Huawei fixture in all three modes |
| Safe translation | Template placeholders retain dynamic values; command text is unchanged |
| Theme and fonts | Actual QFont fallback families; valid light foreground and palette binding; panel title updates |
| Settings/sidebar | Modal dialog, outside dismissal, sidebar collapse and compact overlay expansion through mouse clicks |
| Panel visibility | Hide all three via the menu, restore, verify both editor contents are retained |
| Panel order | Mouse-drag the header grip across the workspace; verify order and editor identity |
| Editor zoom/gutters | Ctrl+wheel event affects only one editor; reset works; 1/2/3/4/5-digit gutters grow |
| Context menu | Actual context-menu event; Chinese menu items; reset action is clickable |
| Text selection | Select the page heading, click empty space, verify selectedText becomes empty |
| Export combinations | 18 scope/format/order combinations; JSON structure, code placement and line counts |
| Export consistency | Confirm a snapshot, edit source, save and verify the confirmed snapshot is retained |
| Export cancellation | Cancel/outside dismissal writes nothing; confirmation opens save flow; system cancellation clears snapshot |
| Layout | QML geometry and screenshots at 960, 1280, 1440 and 1920 widths; light/dark and Chinese/English |
| Future vendors | Additional registry entry reaches controller choices and detected vendor without GUI conditionals |

Ruff formatting/lint and strict Mypy are release gates. GitHub Actions executes the full suite
and a synthetic QML/export smoke run on Windows, Ubuntu and macOS. The CI artifact includes
screenshots and `smoke-result.json`; it contains only synthetic test data.

## Portable acceptance

The Windows standalone application is built with `pyside6-deploy`/Nuitka and the GUI PE subsystem.
The portable ZIP contains the executable, dependency DLLs, QML, translation catalogs, fonts and
license notices. The explicit `--smoke-test OUTPUT` mode checks packaged startup, analysis,
three export formats, settings/export dialogs and screenshot capture using isolated preferences
and disabled history. Release acceptance repeats this after fresh extraction.

## Limits

Automated Linux/macOS validation uses Qt's offscreen platform; it does not establish pixel-identical
rendering across operating-system rasterizers. Windows also receives real-window visual and
packaged-executable checks. Static configuration analysis remains conservative and does not prove
behavior on physical network devices. The application is not Authenticode-signed.
