# v2.0 acceptance record

This record separates source tests, compiled-runtime checks, installer checks, signatures, and
environment limits. Candidate hashes below identify CI run
[`35126947726`](https://github.com/Kokomi-maomeng/NetConfigLint/actions/runs/35126947726)
at commit `e7c2718`; the tagged release publishes its own `SHA256SUMS.txt`.

## Source, H3C, and UI gates

- Final local Windows gate: Ruff format/check passed, mypy passed for 79 source files, and
  `537 passed` on Python 3.13 / Qt 6.11.2.
- The final GitHub matrix passed all 17 jobs: Windows, Ubuntu, and macOS source/UI checks across
  Python 3.12/3.13 and Qt 6.9/6.11, plus a compiled desktop build on every platform.
- H3C acceptance covers deterministic Comware detection, exact source retention, 43 H3C rule
  registrations, supported valid/invalid fixtures, and source-linked UNKNOWN results for every
  unmodeled command. It does not claim to emulate undocumented hardware or release behavior.
- UI tests cover the live full-card drag proxy and settle motion, integrated title bar, icon
  assets, Material motion tokens, and the absence of the About-page horizontal scrollbar artifact.
- At `e7c2718`, the bounded repository/history scan checked 636 current files and 1002 reachable
  blobs with zero current secret/path findings. One pre-v1.5 non-noreply author identity remains
  explicitly classified as historical metadata.
