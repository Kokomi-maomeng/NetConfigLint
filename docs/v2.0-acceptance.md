# v2.0 acceptance record

This record separates source tests, compiled-runtime checks, installer checks, signatures, and
environment limits. Historical candidate hashes are intentionally omitted: the tagged release
publishes its own `SHA256SUMS.txt`, and the release files must be checked against that manifest.
See the [v2.0 audit report](v2.0-audit-report.md) for findings and evidence limits.

## Source, H3C, and UI gates

- The previous candidate passed the local Windows quality gates and GitHub's Windows, Ubuntu,
  and macOS source/UI matrix and compiled desktop builds. The release commit must pass its own
  checks; previous hashes and green runs are not substituted for that result.
- H3C acceptance covers deterministic Comware detection, exact decoded-source retention, 47 H3C rule
  registrations, supported valid/invalid fixtures, and source-linked UNKNOWN results for every
  unmodeled command. It does not claim to emulate undocumented hardware or release behavior.
- UI tests cover the live full-card drag proxy and settle motion, integrated title bar, icon
  assets, Material motion tokens, and the absence of the About-page horizontal scrollbar artifact.
- The release pipeline repeats source/package privacy scanning. An older non-noreply commit
  author identity is historical metadata. GitHub's public two-parent PR merge also retains the
  account's author email; the audit records and accepts only that identifiable release-HEAD
  attribution, while still rejecting any other new non-noreply identity or secret finding.

## Windows

- The compiled standalone passed native Direct3D 11 and forced Software smoke on Python 3.13.2 /
  Qt 6.11.2, with three exports and no captured QML errors.
- A candidate portable ZIP passed SHA-256, x64 GUI subsystem, a fresh Chinese-and-space
  extraction path, native/software smoke, a restricted non-admin token, system-only PATH, no
  console child, no unwanted history, responsive-window, and clean-exit checks.
- The ZIP license and release audits checked dependency notices, source resources, reviewed Qt
  binaries, and current-file privacy findings. Recheck the tagged release artifact separately.
- WiX produced an x64 MSI with install-base selection, an automatically appended
  `NetConfigLint` folder, optional all-users Start Menu/Desktop features, major-upgrade handling,
  and separate keep-history/delete-all uninstall entries. Two host MSI cycles were executed;
  an ephemeral Windows CI gate repeats both choices against the release build, including
  installed-executable smoke, shortcut presence, data retention/deletion, and an unrelated-file
  preservation check. The exact pass/fail evidence belongs to the matching CI/release run.
- Signature status: `NotSigned`. No trusted Authenticode identity exists locally or in repository
  secrets; the package is deliberately named `-unsigned.msi` and must not be described as signed.

## Debian 13

- An amd64 DEB candidate was installed on the authorized Debian 13 VM.
- Package metadata declares the dependency closure and `Installed-Size: 207904`; APT displayed
  approximately 213 MB instead of the previous erroneous zero-byte estimate.
- Installed native OpenGL and forced Software Xvfb smoke both passed with v2.0.0, three exports,
  default Snippet mode, and zero captured QML errors.
- Keep-data uninstall removed the package while retaining config, data, and cache sentinels.
  Reinstall followed by delete-all uninstall removed `/opt/netconfiglint` and all three bounded
  NetConfigLint user namespaces while preserving an unrelated user file.

## macOS

- The hosted macOS runner built the `.app` and PKG and passed native Metal and forced Software
  smoke with three exports and zero QML errors. No user-owned Mac was available for an additional
  installation test, so this is not presented as broad hardware compatibility acceptance.
- Signature/notarization status: unavailable because no Apple Developer application/installer
  identities or notarization key are configured. The package is deliberately named
  `-unsigned.pkg`.
