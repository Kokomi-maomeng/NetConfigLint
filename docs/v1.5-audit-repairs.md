## 默认检查模式

| 模式 | 面向用户的说明 |
| --- | --- |
| 配置片段（默认） | 粘贴部分配置，检查其中的问题；未提供的配置不会直接判为缺失。 |
| 完整配置 | 粘贴整台设备的配置，检查配置缺失、引用冲突和安全风险。 |
| 配置与运行快照 | 粘贴完整配置和路由、邻居等查询结果，结合已支持的运行信息检查。 |

## 结果边界

离线检查只对已有配置和支持的查询结果给出结论；未支持、证据不足、作用域不明或设备能力不确定时
保留 Unknown / Cannot Verify。测试通过不代表覆盖全部 VRP 命令、全部设备版本或全部硬件。

发布检查区分本次新增内容和既有公开历史。本次提交使用项目 noreply 身份；旧公开历史中已有的个人
作者邮箱另行标记，不将其误报为本次新增泄露，也不声称旧历史已经清理或擅自改写公开历史。
