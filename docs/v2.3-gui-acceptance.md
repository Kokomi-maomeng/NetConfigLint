# NetConfigLint v2.3 GUI 与 Windows 便携包验收

日期：2026-09-27。本记录对应 v2.3.0 发布候选源码与本地 Windows 便携包；GitHub 发布包由工作流独立构建，应按实际下载文件核对。

## 修改

- 配置检查工作区四角统一使用 28 逻辑像素圆角。
- 设置的四个分组默认收起；用户在同一次程序运行中展开或收起后，关闭并重新打开设置仍保持状态，重启程序恢复默认。
- 配置内容和临时编辑区将真正的空行绘制为约一个字符宽的圆角色块；被选中的空格、Tab 按编辑器实际字宽补绘。补绘层通过坐标映射与文字行对齐，避免色块落到下一行。Ctrl+A 保留原视口位置；文本缩短后将旧滚动位置限制在新内容范围内，避免短文仍停留在空白视口。选区补绘只处理视口附近的选中文本，避免长配置一次创建成千上万个图形项。
- 编辑卡片按完整标题、操作按钮与至少五位数的 `当前行 / 总行数` 计算最小宽度；位数继续增长时，卡片和窗口最小宽度随之增长。
- 两个编辑区右键菜单加入带图标的“搜索”和“清空”等操作。菜单项悬停蒙版使用透明度动画，指针离开后淡出；按下反馈保留动画，禁用项仍显示图标，可用与不可用的文字和图标在深、浅主题中采用对比更明显的颜色。Ctrl+F 在当前编辑区打开带开合动画的悬浮搜索卡片，再按一次关闭；若搜索卡片打开期间重新选中了有效单行文字，Ctrl+F 将其填入搜索栏并保持打开。右键菜单的“搜索”始终执行打开操作。仅六点拖动图标可移动卡片，悬停会变色并显示圆角“移动卡片位置”提示；卡片可从四边和四角缩放，支持上一处、下一处、循环查找、区分大小写、正则表达式和 55%–100% 透明度。单行选中文本会自动填入搜索框，选中的行尾换行会去除，多行选择不会作为搜索词。修复搜索框聚焦时标签压在输入框边线上的问题，让正则 `\r\n` 兼容 Qt 编辑器规范化后的 LF 换行，并在匹配换行时显示上一行行尾的定位标记。搜索结果采用 90 毫秒输入防抖，关闭卡片后不再因编辑器内容变更而执行隐藏搜索。只读配置预览不能清空。
- 侧边栏普通宽度下只保留布局容器的一次宽度动画，导航内容固定布局宽度；窄窗口浮层仍有独立开合动画，减少每帧重复布局。窗口最小宽度按工作区卡片计算，侧边栏在剩余宽度不足时自动进入浮层模式，避免窄窗口因侧栏展开被推宽后无法收起。

## 本机验证

- Windows 11、Python 3.13.2、PySide6 6.11.2：完整 `pytest` **577 passed**；Ruff 格式和规则、严格 mypy（86 个源码文件）和 `git diff --check` 通过。Qt 交互测试覆盖两处编辑器的选区及补绘坐标、长配置的视口范围绘制、Ctrl+A 视口、动态标题宽度、设置会话状态、正则换行/单词边界/零宽匹配与行尾标记、仅图标拖动、选中文本自动填充、Ctrl+F 开关与重新选择、提示圆角、菜单悬停淡入淡出和深浅主题禁用态；此前另有离屏截图人工检查。
- Debian 13 GUI 虚拟机、Python 3.13.5、PySide6 6.11.2：完整 `pytest` **577 passed**；1920×1080 X11 虚拟显示的新增 GUI 交互测试 **3 passed**；在已启动的 GNOME 桌面 Xwayland `:0` 上执行源码版 GUI 冒烟，版本 2.3.0、三种导出和零 QML 错误均通过。GNOME 桌面当前为 1280×800，直接以 1600 像素测试窗口运行新增自动化时部分模拟点击未命中；该窗口尺寸的交互验收以同一虚拟机中的 1920×1080 X11 结果为准。
- Windows x64 便携 ZIP 从当前源码完整重建。独立解压验收通过原生和软件渲染、三个导出格式、零 QML 错误、普通用户且仅系统 PATH、Unicode/空格路径、窗口响应、无控制台子进程和正常退出。
- ZIP 内有 `portable.flag`，无 `history/history.json` 或 `temporary/editor.txt`；发布候选包是空白数据状态，不包含本机原有历史或临时文本。许可清单验证通过。相对 `main` 基线的当前文件、可达 Git 历史和 ZIP 资源/隐私扫描零命中；旧提交的公开 Git 元数据单独保留在审计报告中，随包 Qt DLL 的特征命中用保存的 PySide6 Essentials 6.11.2 官方 wheel 字节校验排除。
- 重建前旧暂存目录的 `history/history.json` 含 1 条历史记录，已先备份到本机忽略目录 `archive/user-data-backups/v2.3-before-rebuild-2026-09-27-0425/` 并核对文件哈希；该数据未进入新 ZIP。
- 发布候选相对 `main` 无新增非 noreply Git 身份元数据；已有公开提交的 3 项作者或提交者元数据命中属于既存历史。本地扫描记录在 `build/v23-final-audit-main.json`。发布前需再次审计最终提交及远端资产。
