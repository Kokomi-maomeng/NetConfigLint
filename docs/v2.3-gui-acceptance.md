# NetConfigLint v2.3 本地 GUI 与便携包验收

日期：2026-09-27。此版本仅在本机生成供试用，未上传、签名或公开发布。

## 修改

- 配置检查工作区四角统一使用 28 逻辑像素圆角。
- 设置的四个分组默认收起；用户在同一次程序运行中展开或收起后，关闭并重新打开设置仍保持状态，重启程序恢复默认。
- 配置内容和临时编辑区将选中的空行及仅含空格的行绘制为完整行宽的选区；Ctrl+A 保留原视口位置。
- 编辑卡片按完整标题、操作按钮与至少五位数的 `当前行 / 总行数` 计算最小宽度；位数继续增长时，卡片和窗口最小宽度随之增长。
- 两个编辑区右键菜单加入“搜索”和“清空”。Ctrl+F 在当前编辑区打开悬浮搜索卡片；卡片可移动、从四边和四角缩放，支持上一处、下一处、循环查找、区分大小写、正则表达式和 55%–100% 透明度。只读配置预览不能清空。
