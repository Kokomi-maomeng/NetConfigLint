# NetConfigLint v2.3 本地 GUI 与便携包验收

日期：2026-09-27。此版本仅在本机生成供试用，未上传、签名或公开发布。

## 修改

- 配置检查工作区四角统一使用 28 逻辑像素圆角。
- 设置的四个分组默认收起；用户在同一次程序运行中展开或收起后，关闭并重新打开设置仍保持状态，重启程序恢复默认。
- 配置内容和临时编辑区将选中的空行及仅含空格的行绘制为约一个字符宽的圆角色块；Ctrl+A 保留原视口位置。选区绘制仅扫描选中的行，避免每次选择都拆分整份配置。
- 编辑卡片按完整标题、操作按钮与至少五位数的 `当前行 / 总行数` 计算最小宽度；位数继续增长时，卡片和窗口最小宽度随之增长。
- 两个编辑区右键菜单加入带图标的“搜索”和“清空”等操作，菜单项悬停背景为圆角。Ctrl+F 在当前编辑区打开悬浮搜索卡片；仅六点拖动图标可移动卡片，悬停会变色并显示圆角“移动卡片位置”提示；卡片可从四边和四角缩放，支持上一处、下一处、循环查找、区分大小写、正则表达式和 55%–100% 透明度。单行选中文本会自动填入搜索框，选中的行尾换行会去除，多行选择不会作为搜索词。修复搜索框聚焦时标签压在输入框边线上的问题，并让正则 `\r\n` 兼容 Qt 编辑器规范化后的 LF 换行。搜索结果采用 90 毫秒输入防抖，关闭卡片后不再因编辑器内容变更而执行隐藏搜索。只读配置预览不能清空。
- 侧边栏普通宽度下只保留布局容器的一次宽度动画，导航内容固定布局宽度；窄窗口浮层仍有独立开合动画，减少每帧重复布局。
