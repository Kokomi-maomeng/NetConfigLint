## 验证与交付边界

新增回归覆盖上述原失败前缀、保存/取消/失败保护、分页全文编辑与搜索、原始行号、对象撤销、资料迁移对账、参数分类、来源保留和 QML 可见交互。本地 Windows 全量测试 901 项通过（90.74% 覆盖率），性能专项通过；格式、Ruff、Mypy 与 Bandit 门槛通过。最终发布使用同一源码提交的 CI 制品，并在公开下载后复核 SHA-256。安装程序、便携包、源码隐私扫描是独立门槛。

Windows 便携 ZIP 解压后运行 NetConfigLint.exe，无需安装 Python。安装程序为 Windows x64 MSI、Linux amd64 DEB、macOS arm64 PKG。发布文件名如包含 unsigned，表示没有签名；macOS 无签名、公证及用户实体 Mac 验收。Linux 用户环境实测为 Debian 13 GUI；托管 macOS 构建及源码检查不代表所有 Mac 硬件验证。

静态分析不能证明线缆、邻接、转发、对端模式或全部型号/板卡/许可证适用性。未实现的语义继续呈现待校验/未验证。总结式历史不包含源文，用户主动保存的配置、全文历史、草稿和导出文件仍须自行按敏感资料管理。
