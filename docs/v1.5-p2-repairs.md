## 关联行为与限制

- 缺失类判断仍受模式、VPN、地址族、采集完整性和解析证据限制，不把 Unknown 变成肯定结论。
- 默认模式与三种说明文字由主任务统一处理；本阶段不修改版本号或发布。
- 取消和限额覆盖输入、解析、规则及 GUI 结果交接；超限保留未完成标记，禁止显示为完整检查通过。
- 仅对已有官方证据支持的具体型号 / 版本应用 profile 默认值；其余使用通用规则。
  实验 command tree 移入 `experiments/`，不再暗示其参与生产检查。
- 支持的源码依赖范围为 Python 3.12 / 3.13、Qt 6.9–6.11；发行构建锁定 Python 3.13.2、
  Qt 6.11.2 和 Nuitka 4.2。CI 使用 Win/mac 可安装的 Python 3.12.10，另加 Linux 3.12.14。
- 许可材料包括完整 Apache 2.0、Qt / PySide / shiboken / Python / 字体及实际分发依赖，
  并纠正 Nuitka 的许可标注，保留其运行时例外。构建时核对实际文件来源和哈希，生成 SBOM。
- 原生 Windows 证据来自当前测试环境；Linux / macOS 的最终构建与桌面烟雾以发布 CI 为准，
  不等同于所有显卡、缩放比例、桌面会话或独立标准用户账号的验证。
