# Reviewed redistribution material

`sources.json` was generated by `scripts/update_license_catalog.py` from official
Qt/PySide 6.11.2 tagged trees. Every retrieved file was checked against its Git blob
SHA1 and recorded with SHA256. Retrieval uses only public upstream files; release
builds consume this checked-in catalog offline.

Qt attribution files are preserved verbatim (some contain multiline JSON strings).
The collector follows both `LicenseFile` and `LicenseFiles`, including license text
embedded in a referenced header. Source-module attributions include build/test and
other-platform dependencies; only SBOM file mappings indicate actual distributed
runtime components. Commercial/GPL texts in the upstream license directory do not
change the LGPL option selected for the qualified dynamic runtime.

Additional exact materials: CPython Windows 3.13.2 installation LICENSE.txt;
Nuitka 4.2 wheel's LICENSE, LICENSE-RUNTIME and NOTICE; OpenSSL tag openssl-3.0.15
LICENSE.txt; Microsoft's Visual-C-Runtime-2015-2022-License-1.docx (paragraph text);
Qt 6.11 Mesa and LLVM attribution license blocks. Their primary URLs are in
`components.json` and `THIRD_PARTY_NOTICES.md`. Full original license terms are
preserved; generated SBOM paths omit the build machine's absolute paths.
